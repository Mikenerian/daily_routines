プライバシーポリシー

生活ログ同期 ／ 最終更新日: 2026年9月15日

「生活ログ同期」（以下、本ツール）は、作者本人のみが利用する個人用のツールです。本ポリシーは、本ツールがGoogleユーザーデータをどのように取得し、利用し、保存し、共有するかを説明します。

1. 取得するデータ

本ツールは Google Health API を通じて、利用者本人が許可した範囲で次のデータを読み取ります。

  • 運動とフィットネス（googlehealth.activity_and_fitness.readonly）— 運動セッションの種目、開始時刻、運動時間、距離、消費カロリー、および1日ごとの歩数
  • 健康指標（googlehealth.health_metrics_and_measurements.readonly）— 1日ごとの安静時心拍数、および運動セッション中の平均心拍数

いずれも読み取り専用です。本ツールがGoogle上のデータを作成、変更、削除することはありません。上記以外のGoogleユーザーデータ（メール、連絡先、位置情報、カレンダー等）は取得しません。

2. データの利用目的

取得したデータは、利用者本人が自身の運動量や生活リズムを週単位で振り返るためにのみ利用します。他の目的には利用しません。

3. データの保存

取得したデータは、利用者本人が所有するNotionワークスペース内の非公開データベースに保存されます。本ツールの作者は、これ以外の場所にデータを保存するサーバーやデータベースを運用していません。認証に用いるトークンは、実行環境（Google Apps Script）の非公開のプロパティ領域にのみ保管されます。

4. データの共有

取得したデータを第三者に販売、譲渡、開示することはありません。広告目的での利用、および利用者の信用力の判断や与信目的での利用も行いません。人間による閲覧は、利用者本人による閲覧を除き行いません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の利用と他者への移転は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に準拠します。

6. データ保持と削除

利用者は、Googleアカウントの権限設定からいつでも本ツールのアクセス権を取り消すことができます。取り消した時点で、本ツールは新たなデータの取得を停止します。すでにNotionに保存された記録は利用者本人が所有しており、Notion上で直接削除できます。

7. 本ポリシーの変更

本ポリシーを変更した場合は、このページを更新し、最終更新日を改めます。

8. お問い合わせ

本ポリシーに関するお問い合わせは ogakuzunyanko@gmail.com までご連絡ください。

Privacy policy (English summary)

Seikatsu Log Sync is a personal, single-user tool. Through the Google Health API it reads only the authorizing user's own workout sessions, daily step counts, and daily resting heart rate, using read-only scopes. It never creates, modifies, or deletes data in Google Health. The retrieved data is written solely to a private Notion database owned by that same user, and OAuth tokens are held only in the private script properties of the execution environment. The data is never sold, transferred to third parties, used for advertising, or used for creditworthiness or lending purposes, and is not read by any human other than the user. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
